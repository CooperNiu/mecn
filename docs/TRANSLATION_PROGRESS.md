## 🔧 Translation Guidelines / 翻译指南

### Naming Convention / 命名规范
- English files use `_EN.md` suffix
- Example: `TESTING.md` → `TESTING_EN.md`

### Content Structure / 内容结构
- Keep same structure as Chinese version
- Maintain code examples unchanged
- Translate comments and descriptions only
- Preserve all links and references
